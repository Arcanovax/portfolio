# Description

The Answer Protocol is a project that aims to learn us create our own small, persistent-feeling world where multiple players can explore rooms, chat, and cooperate in real time. Our server will speak a simple, line-based TCP protocol, and our two clients — one command line and one graphical — will bring that world to life. The goal of this project is to build a Multi-User Dungeon (MUD) — a shared-world retro text adventure. The primary technical objective is to design a TCP server capable of handling multiple concurrent connections while executing asynchronous code to manage real-time events.
